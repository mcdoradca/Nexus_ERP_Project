# ## Modul: MTool HQ - Generator Kart SDS (UE 2020/878) - Wieloplatformowa Ekstrakcja RTF i Odporny Fallback na Silnik Natywny (ADR-066)
**Data:** 2026-09-14
**Zmiany:**
1. **[NEUTRALIZACJA BŁĘDU SPAWN POWERSHELL ENOENT NA LINUXIE (OVH VPS)]**
   - W `SDSRtfConverter.convertToPdf` wprowadzono natychmiastową asercję platformy: `process.platform === 'win32'`. W środowiskach Linux/Docker próby uruchamiania procesów Windowsowych są natychmiast blokowane bez błędu ENOENT.
2. **[WIELOPLATFORMOWY, DWUWARSTWOWY POTOK W SDSDocumentParser]**
   - W `SDSDocumentParser.extractText` zaimplementowano architekturę z pełną osłoną `try...catch`:
     * Na stacjach Windows system podejmuje bezpieczną próbę użycia mostka Word COM.
     * W przypadku braku Worda, błędu PowerShell lub w środowisku produkcyjnym Linux VPS (Ubuntu / OVH), system natychmiast, bezprzerwowo i bez rzucania błędu 500 przełącza się na natywny silnik `SDSRTFParser` w czystym Node.js.
3. **[CERTYFIKACJA ZERO-DEPENDENCY SILNIKA RTF]**
   - Potwierdzono, że natywny silnik JavaScript `SDSRTFParser` bez udziału Worda ani zewnętrznych procesów wyodrębnia 100% składników LIMS (5/5 substancji w karcie Orchidea e Vaniglia: etanol, aldehyd anyżowy, kumaryna, BHT, toluen) oraz wszystkie parametry Sekcji 9.
4. **[TESTY I BRAMKI JAKOŚCI]**
   - Wykonano symulację platformy Linux (`process.platform = 'linux'`) dla całego zestawu `tests/sds.rtf.test.js` (6/6 PASSED).
   - Wszystkie 122 testy systemowe `npm test` oraz 7 testów regulacyjnych `tests/sds.compliance.test.js` zakończone ze statusem 100% pozytywnym.
