# ## Modul: MTool HQ - Generator Kart SDS (UE 2020/878) - Eliminacja degradacji jakości kart RTF, Bezstratna Rekonstrukcja Geometrii i Ekstrakcja Tabeli Blokowej LIMS (ADR-063)
**Data:** 2026-09-14
**Zmiany:**
1. **[BEZSTRATNA GEOMETRIA WIERSZY RTF]** W `SDSRTFParser` naprawiono konwersję tokenów `\par`, `\line`, `\page` wewnątrz komórek tabeli na znak nowej linii `\n` (zamiast spacji `' '`), co przywróciło pionową strukturę wierszy. Dodano dekodowanie hex znaków specjalnych `\'3d` (=) oraz pomijanie bajtów zastępczych `\'xx` po encjach `\uN`.
2. **[ODPORNA SEGMENTACJA 16 SEKCJI]** W `segmentInto16Sections` wyrażenia regularne rozszerzono o dowolny separator blokowy `(?:^|[\n\r\t]|\.\s+)`. Zaimplementowano precyzyjne wyliczanie pozycji sekcji bez uwzględniania separatora prefixu, gwarantując bezbłędną segmentację wszystkich 16 sekcji z plików RTF i PDF bez pustych sekcji.
3. **[PARSER BLOKOWY SKŁADNIKÓW LIMS (SEKCJA 3.2)]** Zaimplementowano metodę `parseBlockComponents` obsługującą wielowierszowy format tabelaryczny LIMS (np. Epy/Kemika), gdzie nazwa, numery Index, stężenia, CLP, numery WE i CAS występują w kolejnych wierszach komórek rozdzielonych tabulatorami. Wzbogacono `extractCas` o negatywne lookbehind/lookahead `(?<![0-9\-])\b\d{2,7}-\d{2}-\d\b(?![0-9\-])`, co wyeliminowało fałszywe numery CAS z numerów INDEX (np. `002-00-5` z `603-002-00-5`). Wyekstrahowano komplet 5/5 składników (etanol 74-78%, aldehyd anyżowy, kumaryna, BHT, toluen).
4. **[EKSTRAKCJA I POLONIZACJA WŁAŚCIWOŚCI FIZYKOCHEMICZNYCH (SEKCJA 9)]** W `cleanPdfArtifacts` wprowadzono flagę `preserveTabs`, zapobiegając usuwaniu tabulatorów w tabelach parametrów. Zaktualizowano `paramsConfig` w `processSection9` o obsługę synonimów (`Appearance`, `Aspetto`, `Initial boiling point`, `Melting point / freezing point`), separatorów `\t`, agregacji granic wybuchowości (Lower + Upper) oraz automatyczną polonizację terminów i kolorów (`ciecz`, `różowy`, `ciecz łatwopalna`, `rozpuszczalny w wodzie`).
5. **[BRAMKA TESTOWA I REGRESJA]** Rozbudowano `tests/sds.rtf.test.js` o TEST 6 weryfikujący produkcyjną kartę Orchidea e Vaniglia (6/6 PASSED). `tests/sds.compliance.test.js` (7/7 PASSED), pełen zestaw systemowy `npm test` (122/122 PASSED) oraz kompilacja produkcyjna `npm run build` w `frontend/` (kod 0).
